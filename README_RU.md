# Visual Projection Translator для TauriTavern / SillyTavern

Расширение для визуального перевода уже отображённых ответов персонажей. Оно меняет **только `nodeValue` текстовых DOM-узлов**; исходный объект сообщения/история чата не редактируется. Теги и атрибуты HTML не отправляются переводчику и не переводятся, поэтому `<details>` остаётся `<details>`, а уже отработавшие Regex-форматирование и Markdown-структура не ломаются из-за замены текста в истории.

## Возможности

- Кнопка `文/A` у каждого ответа персонажа: нажми для перевода, повторно нажми `原` для восстановления оригинала.
- Автоперевод новых ответов персонажей после паузы в генерации.
- Кнопки перевода/восстановления видимых ответов.
- Переводчик на выбор: Google или Яндекс; целевой язык по коду (`ru`, `en`, `de`, `ja` и т. п.).
- Блоки `<code>` и `<pre>`, поля ввода, скрипты/стили и помеченные `.notranslate` фрагменты пропускаются.
- Настройки сохраняются локально в WebView.

## Установка в TauriTavern на Android без GitHub

1. Скачай `VisualProjectionTranslator.zip` и распакуй его файловым менеджером телефона.
2. Внутри архива будет папка `VisualProjectionTranslator` с файлами `manifest.json`, `index.js`, `style.css` и `README_RU.md`.
3. Скопируй **всю папку** `VisualProjectionTranslator` в каталог данных TauriTavern:

   **Пользовательская установка:**
   `data/default-user/extensions/VisualProjectionTranslator/`

   **Глобальная установка:**
   `data/extensions/third-party/VisualProjectionTranslator/`

   Если папок `extensions` или `VisualProjectionTranslator` нет — создай их. В конечной папке `VisualProjectionTranslator` файл `manifest.json` должен лежать непосредственно внутри, а не в дополнительной вложенной папке.
4. Полностью закрой и заново открой TauriTavern (либо перезагрузи его интерфейс, если в твоей версии есть такая команда).
5. Открой панель **Extensions / Расширения** и найди **Visual Projection Translator**. Включи его.
6. В настройках расширения выбери переводчик и язык. Для перевода старых/уже загруженных сообщений нажми кнопку `文/A` у нужного ответа или «Перевести видимые ответы».

### Где найти папку `data`

Путь зависит от способа установки и настроек хранилища твоей версии TauriTavern. Ищи каталог данных приложения, в котором уже лежат `default-user`, `characters`, `chats`, `extensions` и другие данные. Не клади расширение в папку `Downloads` — загрузки ZIP недостаточно, файлы должны оказаться внутри каталога данных TauriTavern.

Если Android не даёт файловому менеджеру открыть каталог данных приложения, перемести/импортируй архив через доступный в твоей сборке TauriTavern инструмент резервного копирования/управления данными либо воспользуйся файловым менеджером с доступом к каталогу приложения. Названия пунктов меню отличаются между сборками; расширение не устанавливается одной лишь кнопкой «Install from Git URL».

## Важные ограничения

- Это первая версия, разработанная под совместимую со SillyTavern разметку (`.mes`, `.mes_text`). У меня нет твоей установленной сборки для проверки внутри Android-приложения, поэтому после установки проверь одну короткую реплику. Если кнопки не появились, вероятно, конкретная сборка изменила CSS-классы сообщений или путь загрузки расширений.
- Google используется через неофициальный веб-эндпоинт `translate.googleapis.com`, без ключа. Это не гарантированный публичный API; он может ограничиваться или блокироваться.
- Яндекс использует старый неофициальный JSONP-эндпоинт веб-переводчика, без ключа. Он может перестать отвечать, блокировать WebView или изменить параметры. Если Яндекс не срабатывает, переключи провайдера на Google.
- Выбранному сервису отправляется текст каждого видимого текстового фрагмента. Не включай перевод чувствительных сообщений, если не хочешь передавать их внешнему сервису.
- Для сохранения HTML-структуры текстовые узлы переводятся по отдельности. В сообщениях с большим количеством вложенной разметки качество отдельных фраз может быть хуже, чем у перевода целого абзаца.
- Расширение не меняет сохранённый чат, но визуально заменяет текстовые узлы открытой страницы. Перерисовка сообщения приложением может вернуть оригинальный вид — после этого нажми перевод ещё раз.

## Удаление

Отключи расширение в панели Extensions, затем удали папку `VisualProjectionTranslator` из каталога расширений. Само содержимое чатов при этом не меняется.
