# Visual Projection Translator — исправленная версия 1.3.0

## Что изменено

- Кнопка сообщения показывает `…` во время ручного и автоматического перевода.
- Нажатие на `…` останавливает текущий запрос; после завершения отмены перевод можно сразу запустить повторно.
- Вместо непонятных символов на кнопке теперь понятные подписи: `Перевести` и `Оригинал`.
- Добавлена подписка на события SillyTavern `CHARACTER_FIRST_MESSAGE_SELECTED` и `MESSAGE_SWIPED`.
- Автоперевод также запускается при появлении нового сообщения в чате через DOM-наблюдатель.
- Добавлено корректное снятие подписок на события при выгрузке расширения.

## Обновление репозитория через GitHub на телефоне

1. Открой ZIP и извлеки три файла: `manifest.json`, `index.js`, `style.css`.
2. В репозитории GitHub открой каждый одноимённый файл и выбери Edit (карандаш) либо Upload files, если доступно в мобильном интерфейсе.
3. Замени содержимое файлов из архива и сохрани изменения в `main`.
4. В SillyTavern обнови расширение обычным способом.

Настройки расширения хранятся в localStorage и не должны сброситься при замене файлов.
